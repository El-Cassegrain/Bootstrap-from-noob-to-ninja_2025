# Pour toute la durée de la formation
- Ouvrez chaque consignes.md avec un clic droit "ouvrir dans l'explorateur".
- Regardez l'image du resultat attendu du chpitre en cours.
- Ouvrir le fichier index.html dans un navigateur, de préférence grâce à l'extension "Live Server", puis lisez le.
- Gardez précieusement la page de la documentation de Bootstrap 5.3 ouverte dans un onglet du navigateur pendant toute la durée de votre formation Bootstrap, car vous allez être obligé d'aller y piocher des informations. Heureusement la documentation et très bien faites et très complète.
- Si vous ne parvenez pas à faire un exercice, cherchez d'abord dans la documentation, puis si vous êtes encore bloqués, prompter une IA comme chatGPT en lui demandant quoi faire après aveoir fourni le document ui nous intéresse, essayez au maximum de ne pas arriver à cette étape.
- Un développeur n'est pas quelqu'un qui sait tout par coeur, mais qui sait ou aller chercher l'information (la doc, le plus souvent)
- Enfin, si vous êtes toujours bloqués, après avoir tout essayé, envoyez moi un message.
- Et surtout, Amusez vous ! Et prenez du plaisir pour atteindre le niveau Ninja !

## Étape 1:
- Importez le CSS minifié de Bootstrap dans le ```<head>``` de votre document, depuis le dossier assets/css, afin de charger les styles par défaut de BS. Je choisi d'utiliser une ressource locale, mais vous pouvez utiliser un CDN.
- Importez le bundle.min.js de Bootstrap, depuis assets/js à la fin du ```<body>``` juste avant la balise fermante ; afin de pouvoir bénéficier par la suite des intéractions que nous offrent les composants Bootstrap qui utilisent JavaScript.
- Notez comment les noms de classes utilitaires déclarées dans les balises mettent déja en forme votre front : typo, thème de couleurs, marges du container et du margin-top, styles de boutons, etc...
- Jouez avec les noms de classes et les valeurs vues dans le cours : changez ```btn-primary``` par ```btn-success``` par exemple !
