## Étape 2:
- Allez copier/coller le code de l'exemple du composant Navbar en cliquant sur le bouton et en naviguant jusqu'a l'exemple. Et mettez le au bon endroit dans le template après la balise ouvrante ```<header>``` de votre document, afin d'obtenir le résultat attendu.
- Si vous avez bien importé le JavaScript de Bootstrap à l'étape 1 (précédente), vous devriez avoir un bouton burger, fonctionnel au clic, pour les écrans qui ont un viewport en dessous de lg (< 992px).
- Notez comment les noms de classes utilitaires déclarées dans les balises pemrettent d'aligner les liens à gauche ou à droite ou de centrer sur desktop (à partir de 992px de large)
- Jouez avec les noms de classes et les valeurs vues dans le cours : changez ```ms-auto``` par ```ml-auto``` par exemple !
- Proftez en pour analyser les classes utilisée par le menu, le dropdown, et le disabled ; et voyez leurs effets sur le front.
