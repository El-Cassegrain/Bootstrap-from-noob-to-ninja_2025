## Étape 3:
- Allez chercher la bibliothèque d'icones svg de Bootstrap 5 et importez la dans le ```<head>``` de votre document via le CDN, afin d'obtenir une bibliothèque d'icones prêtes à l'emploi.
- Si vous avez bien importé les icones, vous devriez maintenant pouvoir les utiliser. La convention veut que nous utilisions une balise ```<i class="bi bi-nom-de-mon-icone"></i>```
- Insérez les icones comme dans l'image du résultat attendu.
- Les font-icons, comme leur nom l'indique, sont considérées comme de la typographie, on gère donc leur taille avec une font-size !
- On va modifier la Navbar et intégrer un bouton de Contact avec une icone, puis mettre des icones sur les liens de la navbar et changer pour mettre comme dans l'exemple (résultat attendu) soit "Accueil" / "À propos" / "Crédits"
- Vous aurez besoin des icones ```<i class="bi bi-send">``` / ```<i class="bi bi-person">``` / ```<i class="bi bi-info">``` / ```<i class="bi bi-house">``` pour le menu et le bouton contact. Mettez une classe ms-lg-3 au bouton contact.
